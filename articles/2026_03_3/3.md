# 3. «Симĕс хула» экологи программине хута яраççĕ

Хула ертӳлĕхĕ экологи лару-тăрăвне лайăхлатмалли масштаблă проект çинчен пĕлтернĕ. Çак программа тăрăх пурăнан вырăнсенче сывлăш тата шыв тасалăхне арттарас тĕллев пур.

## 🌱 Планăн тĕп пайĕсем

- **Атмосфера сыхлавĕ:** Пысăк предприятисенче фильтр системисене хăватлантараççĕ.
- **Шыв ресурсĕсем:** 3 тасату станцине модернизацилеççĕ.
- **Симĕс зонăсем:** Хула варринче 7 çĕнĕ парк тăваççĕ.

## 📊 Кăтартусем

> Йывăç лартмалли шучĕ: **25 000**  
> Сывлăшри пăсăклав шайĕ: -40% (план)

## 💰 Финансăлав çăлкуçĕсем

> Республика бюджетĕ: 2.1 млрд тенкĕ  
> Федераци гранчĕ: 0.9 млрд тенкĕ
